Actualización v4: odometría corregida para skid-steer + gráficas arregladas
==========================================================================
Incluye todo lo de la v3 (Inicio, cámara en Operación, cambio de modo en caliente) y además:

  scripts/odometria_vueltas.py   publica también /odom_skid: odometría con vía efectiva
                                 b_ef = 0.191 m (parámetro b_efectiva; 0 = desactivada)
  scripts/detector_vueltas.py    la corregida entra al CSV, a la tabla y a las 3 gráficas
  scripts/volante_web.py         pestaña Odometría: orientación sin saltos en ±180°,
                                 DiffDrive punteada, metros/mm automáticos, línea corregida
                                 y k en vivo (cuánto gira el robot respecto a las ruedas)

Instalar:
  cd ~/ros2_ws_dif
  git switch consola-v2 2>/dev/null || git switch -c consola-v2
  unzip -o ~/Downloads/actualizacion_consola_v4.zip -d ~/ros2_ws_dif
  chmod +x src/mi_robot_diferencial/scripts/*.py
  rm -rf build install log
  colcon build --packages-select mi_robot_diferencial && source install/setup.bash
  ros2 launch mi_robot_diferencial robot_yahboom.launch.py pista:=competencia volante:=true

Comprobar la odometría corregida:
  ros2 topic hz /odom_skid          (debe publicar, al ritmo de /joint_states)

Volver a lo anterior:
  git checkout -- . && git switch competencia-microros
  rm -rf build install log && colcon build --packages-select mi_robot_diferencial && source install/setup.bash
